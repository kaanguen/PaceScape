# Ghost pacing

The current avatar has exactly two reference modes: **preset speed** (`FixedPace`, default) and **all-time personal best** (`AllTimePersonalBest`). The user's treadmill data measures the user, independently of the ghost. Current-run best replay and direct belt-following were removed at the user's request. A side-by-side companion is deferred.

See [ghost comparison](ghost-comparison.md) for setup, persistence, demonstration records, statistics, verification and limits. A new Android build and matching Control server are required (`ghostControlVersion: 1`).
